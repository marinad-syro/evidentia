## Affected Pages/Routes
- `/` — Main search page: input bar, SSE progress feed, recommendation cards
- `/search` (POST or GET) — FastAPI backend endpoint, SSE stream

## Key Interactions to Verify

### Trust Score Formula (`pre_compute/trust.py`)
- Feed a row with all positive signals → assert score = 100 (capped)
- Feed a row with all null fields → assert score = 0
- Feed a row with shared phone (>3 providers) → assert -10 applies
- Feed a row with boilerplate description (<50 chars) → assert +0 for that signal
- Feed a row with recency_of_page_update > 12 months → assert +0 for that signal

### Specialty Lookup (`api/specialty.py`)
- "eye doctor" → maps to `ophthalmology` specialty_id (lookup table hit)
- "retinal specialist" → LLM fallback path (not in lookup table) → returns valid specialty_id
- Unmapped query → returns user-facing error string, not an exception

### Search Endpoint (`api/search.py`)
- Valid query ("I need an ophthalmologist in Bangalore") → SSE stream opens, emits all 5 step events, final `results` event contains ≥1 provider
- Unparseable NL query → endpoint returns 400 with clear error message, not 500
- Zero results within 10km → SSE emits radius-expand message, search retries at 25km

### Tavily Fallback
- Mock Tavily to timeout for all 3 providers → trust scores still returned using precomputed values, no error shown to user
- Mock Tavily to succeed for 1 of 3 → that provider gets +10 live verify bonus, others use precomputed score

### Geocoding
- Valid city name ("Koramangala, Bangalore") → returns lat/lon
- Invalid location ("xyzzy123") → returns geocoding error, not a 500

## Edge Cases
- Query with exactly 1 result → single card rendered correctly (not an empty list)
- Provider with `officialWebsite` = null → Tavily call skipped, precomputed score used
- Provider where Tavily returns empty text → treated as Tavily failure, fallback to precomputed
- LLM verification identifies red flags (placeholder images, wrong address) → trust_delta = -5 or 0, NOT +10
- SSE client disconnects mid-stream → backend does not crash, async tasks are cleaned up

## Critical Paths
1. Full happy path: "I need an eye specialist near Koramangala" → all 5 SSE steps → 3 provider cards with trust scores and "why this one" text
2. Tavily total failure: all 3 verifications timeout → demo still completes without visible error
3. No results at 10km: streaming feed shows radius expansion message, results appear at 25km
